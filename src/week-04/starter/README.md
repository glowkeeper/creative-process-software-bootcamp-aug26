# Week 4 Starter

The Week 3 Short Film Programme Builder, rebuilt as a React application before
any of it has been organised.

The whole page lives in one component in `src/App.jsx`, and all six film cards
are written out by hand. Nothing has been extracted and no button does anything
yet.

The repetition is the point. During the guided build we give the repeated shape
a name of its own.

## Running it

```bash
npm ci
npm run dev
```

`npm ci` installs exactly the versions recorded in `package-lock.json` and
leaves that file alone, so pulling the published Complete afterwards stays
clean.
