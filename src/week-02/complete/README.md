# Week 2 Complete

This is the canonical outcome for the Week 2 guided build. It uses semantic
HTML and a small, responsive CSS system to present all six Stage 1 fictional
films.

The buttons are deliberately visible but do not work yet. Week 3 will add
behaviour.

## Live-build checkpoints

The tutor guide and slides divide the build into Parts 1-9. At Part 5, stop
typing repeated film cards and replace the in-progress `index.html` with the
prepared six-card version in this directory. Continue the live demonstration
with the CSS. This keeps repetition from consuming the session.
