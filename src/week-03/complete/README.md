# Week 3 Complete

This is the canonical outcome for the Week 3 guided build.

The application demonstrates one complete interaction:

1. A visitor selects or removes a film.
2. JavaScript hears the click.
3. The film card and button change visibly.
4. The programme count updates.

The code deliberately keeps all new behaviour in one short script. Forms,
runtime calculation, filtering, dynamic element creation and persistence are
not part of the core Week 3 outcome.
