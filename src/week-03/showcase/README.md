# Week 3 Showcase

This optional vanilla-JavaScript extension demonstrates possibilities beyond
the Week 3 core outcome:

- selection and removal
- a visible programme list
- total runtime and programme-length feedback
- filtering by film form
- a form with validation
- dynamic film-card creation with `createElement()` and `appendChild()`
- event delegation so newly created buttons also work

The Showcase is an inspectable example, not the guided-build target. It does
not use `localStorage`; the fact that selections disappear on refresh creates a
purposeful persistence problem for Week 6.
