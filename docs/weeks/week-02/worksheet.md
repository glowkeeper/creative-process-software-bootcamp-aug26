## 5. Build the Smallest Useful Interface

### Required

- [ ] `index.html` has a meaningful title and page structure.
- [ ] An external stylesheet is linked correctly.
- [ ] The most important content is clear.
- [ ] Repeated content uses a reusable class where appropriate.
- [ ] Colour, type and spacing form a consistent visual system.
- [ ] The page remains usable when the browser becomes narrow.
- [ ] I used fictional, self-created, placeholder or permitted assets only.
- [ ] I committed the change with a clear message.

### If the core interface works

Choose the extension that best improves the same Starting Point:

- strengthen hierarchy or visual identity
- add a useful repeated content item
- improve keyboard focus and hover feedback
- refine the narrow-screen layout
- replace an image dependency with purposeful CSS artwork

Do not add a second page merely to make the project larger.
