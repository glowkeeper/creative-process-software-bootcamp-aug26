## Debugging a Small Interaction

When nothing happens:

1. Save every file and refresh the browser.
2. Open the browser Console.
3. Read the first error, including its file and line number.
4. Check that the script path matches the real folder structure.
5. Check that the selector matches the HTML exactly.
6. Add a temporary `console.log()` inside the event listener.
7. Change one thing, save and test again.

## Course Reference States

- **Starter** - the Week 2 interface before JavaScript is connected
- **Complete** - the small select/remove/count interaction built together
- **Showcase** - optional forms, validation, filtering, runtime calculation and
  dynamic element creation

Showcase is useful for inspection, but it is not a list of Week 3 requirements.
Start with one action and one visible response you can explain.
