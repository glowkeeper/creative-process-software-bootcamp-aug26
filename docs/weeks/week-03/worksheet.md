## 6. If the Core Interaction Works

Improve the same interaction before adding another feature:

- make the response clearer
- add a second state, such as selected/unselected or shown/hidden
- improve hover, focus or selected styling
- apply the understood pattern to repeated items
- handle one likely user mistake

Showcase demonstrates forms, generated elements, calculations and filtering,
but these are not required for Week 3 success.
