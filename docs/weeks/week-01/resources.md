# Week 1 Resources

## About This Guide

The Software Development Bootcamp is designed to be self-contained. Begin with
the course project briefs and worksheet before exploring external resources.

You do **not** need any of the resources below to complete the course successfully.

However, if today's topic has sparked your curiosity, these carefully selected resources provide an excellent place to continue exploring professional software development tools and workflows.

The aim is quality rather than quantity.

## Finding Reusable Assets

### Openverse

https://openverse.org/

Openverse helps find openly licensed images and audio. Always open the original
source, check the specific licence and record the required attribution.

### Creative Commons Licences

https://creativecommons.org/share-your-work/cclicenses/

Use this guide to understand what a Creative Commons licence permits. A search
result is not permission by itself: check the licence attached to the original
asset.

You may also avoid third-party assets entirely by using fictional content,
original artwork, abstract placeholders, or HTML and CSS visual treatments.

## Learning Philosophy

The most valuable software development resources are often the ones you already have:

1. Your own project.
2. Your GitHub repository.
3. Your project board.
4. The official documentation.

Professional developers don't just write code.

They plan, organise, document, review and improve their software throughout its lifetime.

Good software development is as much about process as it is about programming.
